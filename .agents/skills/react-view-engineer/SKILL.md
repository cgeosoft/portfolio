# React View Engineer

## Stack and rules

- React 19 with TypeScript. `Electroview.defineRPC<PortfolioRPC>` in `src/views/src/rpc.ts` is the RPC client bridge.
- Chart.js 4 for visualizations, Lucide React for icons.
- Use `src/views/tsconfig.json` (separate TypeScript context). Do not import `bun` or `node:*` modules here.
- All backend access happens through `rpc.request.<methodName>(payload)`.
- Run `bun run typecheck` after every edit; it checks both the main process and the webview.

## Repo layout

- `src/views/main.ts` - Electroview entry point and React DOM mounter.
- `src/views/index.html` - Webview HTML shell.
- `src/views/style.css` - Compiled Tailwind CSS (generated by `bun run build:css`).
- `src/views/src/App.tsx` - Dashboard application router (dashboard, settings, portfolios, terms views).
- `src/views/src/rpc.ts` - RPC client with `ensureRpcReady()`, `clientLogger`, and `forceFallbackToNativeBridge()` for WebKitGTK bridge failover.
- `src/views/src/components/`:
  - `layout/` - `Header`, `AppMenuBar`, `BottomBar`.
  - `common/` - `AboutModal`, `SetupWizardModal`, `TermsPage`, shared utilities.
  - `portfolio/` - `StatCard`, `PortfolioChartCard`, `AllocationCard`, `HoldingsTableCard`, `TransactionsCard`, `ReportsCard`, `TransactionModal`, `ImportCsvModal`, `ExportPortfolioModal`, `AnalyzePortfolioModal`, `AssistantSidebar`, `MetricInfoModal`, and helpers in `utils.ts` and `report-export.ts`.
  - `settings/` - `SettingsPage` and sections.
- `src/views/src/types/portfolio.ts` - View-level type re-exports.
- `src/shared/rpc-types.ts` - The RPC schema. Read it before adding a new UI-to-backend call.

## Conventions

- Format currency and percent with `fmtCurrency` and `fmtPercent` from `src/views/src/components/portfolio/utils.ts`.
- Use the `cx-card` styling surface and the design tokens from `input.css` (see the `ui-style-engineer` skill).
- Check the RPC bridge is ready with `ensureRpcReady()` before issuing initial requests to avoid dropped packets.
- Use `clientLogger` for webview logging and measured steps.

## Gotchas and pitfalls

- RPC requests can time out. Handle rejection gracefully and surface a user-readable message.
- Tailwind classes used in `.tsx` must exist in the compiled `style.css`. Run `bun run build:css` after adding or editing utility classes.
- Do not break the native bridge failover logic in `rpc.ts`; it exists for WebKitGTK reliability.
- Run `bun run typecheck` after TypeScript edits and commit your change per the release workflow.
