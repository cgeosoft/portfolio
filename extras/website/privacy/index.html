Privacy Notice

This notice says what Portfolio and this website send, who receives it, how long we keep it and how you can ask for deletion.

Notice version 1 • Last updated: November 7, 2026

1. Who is responsible

The controller of this data is Christos Georgiou, who publishes Portfolio under the name cgeosoft.

For a privacy question or request, write to christos@cgeosoft.com.

2. What stays on your computer

Your holdings, quantities, cash balances, transactions, notes and settings stay in a database file on your computer. We have no server that receives them.

3. Two options in the app

Portfolio has two separate options: usage analytics and error reporting. Both are off by default. The app sends nothing to PostHog for an option until you turn that option on. You can change either option at any time in Settings, Privacy & Security. A change works at once.

The legal basis for both options is your consent (GDPR Art. 6(1)(a)). A "no" costs you no feature.

4. Usage analytics

Purpose: to see which features people use, so we can improve them.

What it sends: named events, a random install ID and the notice version you accepted. Events can hold a count, a yes or no value, or the type of AI provider.

Example: the event csv_imported with a count of 42 and the install ID 7f3c...e91a.

Settings shows your install ID. You can copy it or reset it there.

5. Error reporting

Purpose: to find and fix crashes.

What it sends: the error type, a fixed code for the place of the failure, code locations inside the app, the app version, the release channel, your operating system, the processor type and the notice version you accepted.

Example: a TypeError with the code service:uncaught at line 120 of service/main.js, on app version 0.18.0 for Linux.

A report holds no install ID and no error message. Each report has a new random ID, so we cannot link reports to each other or to you.

6. What we never collect

Neither option sends holdings, amounts, ticker symbols, transactions, account names, file paths or anything you type.

7. This website

This website asks for your consent before it loads PostHog. If you accept, PostHog records page views, download clicks with the system and file type, and screenshot zooms, with a random ID that it keeps in your browser storage. An event does not hold the page address, the referring page or your browser type. If you decline, the page makes no request to PostHog. The legal basis is your consent. To change your choice, press Analytics choice at the bottom of the page. When you decline, the site stops the analytics and removes the ID from your browser. The Terms page inside the app does not load PostHog.

8. Who receives the data

PostHog receives this data for us as our processor. We use PostHog Cloud EU, which runs on servers in Frankfurt.

The data can also leave the EU. The PostHog sub-processor list names Cloudflare for traffic at global edge locations, and PostHog companies in Germany and the United Kingdom. That list can change.

PostHog sees your IP address with each request. It does not store the address with the event.

9. How long we keep it

We keep events for 12 months. PostHog deletes expired events in a monthly cleanup, so an event can stay up to about a month longer.

10. Your rights

You can ask for access to your data or for its deletion. You can withdraw your consent at any time. A withdrawal stops new data and does not change what was lawful before it. You can also complain to a data protection supervisory authority.

For usage analytics, send us your install ID from Settings. We need it to find your data. Copy it before you reset it, because a reset gives you a new ID.

For error reports, a report has no ID, so we cannot find the reports of one person.

11. Other connections of the app

The app also connects to other services for its features. We do not receive this data.

  • Prices: ticker symbols go to Yahoo Finance, and to Finnhub or Financial Modeling Prep if you add a key.
  • AI: weights, percentages and tickers go to the AI provider you chose, when you ask. A local model keeps them on your computer.
  • Terms: the Terms page in the app loads from this website.
  • Updates: the app checks GitHub and this website for a new version. This is on by default, and you can turn it off in Settings.
  • Phone briefs: briefs go to Gotify or ntfy, if you turn them on.

These services see your IP address, and their own privacy terms apply.

The website has its own connections. Cloudflare Pages hosts it and receives your IP address, your browser data and the pages you request on each visit. The site also asks the GitHub API for the latest release. The legal basis for both is the legitimate interest in running the site (GDPR Art. 6(1)(f)).

12. Changes

If the data, the purpose or the recipient changes, we raise the notice version and the app asks you again.
