Local Data Sovereignty and Privacy

Portfolio Desktop operates as an offline-first desktop tool. All portfolio holdings, cash amounts, transaction histories, notes, and local configuration files remain stored on your personal device:

Local Database Path: ~/.config/portfolio/data/portfolio.sqlite
  • We do not operate remote servers to collect your personal investment records.
  • We do not require an account, user registration, or cloud login.
  • Anonymous product telemetry is opt-in and disabled by default. When enabled, telemetry sends anonymous application interaction counters only. Telemetry never transmits ticker symbols, financial values, balances, or personal identification.

Artificial Intelligence and LLM Integrations

The Software provides on-demand portfolio briefings using Large Language Models (LLMs).

  • Local Runtimes: When using local models (such as Ollama or llama.cpp), your analysis data does not leave your personal computer.
  • Cloud Providers: When using cloud providers (such as OpenAI, Anthropic, Groq, Gemini, OpenRouter, or DeepSeek), your device communicates directly with the provider using your private API key.
  • AI-generated reports are synthetic text summaries produced by probabilistic models. You must not interpret AI outputs as certified audits or investment recommendations.
