QUESTIONS & ANSWERS

Frequently Asked Questions

Where is my portfolio data stored?

Everything is stored exclusively on your local computer in a secure private database file. No external servers, no cloud databases, and no accounts are required.

How does live market valuation work without cloud syncing?

The application communicates directly with Yahoo Finance from your computer to fetch current quotes, intraday movements, and currency exchange rates. Your holdings and portfolio values are never sent to Yahoo; the app requests only public ticker symbols.

How does the AI Analyst work?

You have full flexibility: run completely offline with local LLM runtimes like Ollama or llama.cpp, or supply your own private API key for cloud providers like Groq, OpenAI, Anthropic, Gemini, OpenRouter, or DeepSeek. Reports are generated strictly on demand.

Which brokers can I import CSVs from?

The CSV import wizard features automatic schema detection for Trade Republic, Scalable Capital, Interactive Brokers (Activity Statement CSV), and Degiro (Account CSV), plus support for standard generic transaction CSV format.

Is Portfolio completely free?

Yes. Portfolio is 100% free and open source. You own your data forever, with zero subscription paywalls or artificial portfolio size caps.
